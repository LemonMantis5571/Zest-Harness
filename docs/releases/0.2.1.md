# Zest 0.2.1 beta

Zest 0.2.1 is the first published beta built from the current master branch.
It expands the desktop chat experience, adds headless serving, and makes the
subscription-provider integrations more complete.

## Highlights

- `/btw [question]` opens a temporary side conversation without adding it to
  the main chat history.
- `zest serve --project PATH` provides a windowless, authenticated loopback MCP
  coordinator, with an explicit approval flow by default.
- Release artifacts include standalone `zest` CLI binaries for Windows and
  Linux, so headless use does not require the WebKit desktop bundle.
- Enabled MCP servers are available as slash commands, and Customize starts
  with the official GitHub MCP entry ready to configure.
- Claude Code sessions now persist across turns, support effort selection, and
  surface real tool names, edit targets, and approval boundaries.
- Chat history, project navigation, Workbench interactions, responsive layout,
  image zoom, links, usage reporting, and provider error handling receive
  reliability and usability improvements.
- The chat header is simplified: command palette and Workbench controls are
  removed from the layout-panel header while the actions remain available from
  the app's command/search actions.

## Upgrade notes

Install over an existing beta. Chats, projects, settings, and provider
configuration are preserved. Review approval cards before accepting changes.

This is beta software. Windows and Linux x64 are the packaged targets;
macOS and ARM packages are not included. Provider usage may be estimated or
unavailable when an endpoint does not report token counts or quota.

Unsigned installers do not prove publisher identity. Verify the downloaded
installer against the matching SHA256 manifest published with the release.

Plugins remain optional and are not included in the official packages.
