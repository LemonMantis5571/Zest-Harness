# Code of Conduct

Zest is an open-source project, and every contributor is expected to make the
project welcoming and useful for others.

Be respectful, assume good intent, give feedback about the work rather than
the person, and keep technical discussions focused. Harassment, discrimination,
personal attacks, doxxing, and sharing private information are not welcome.

Maintainers may remove comments, close issues, or limit participation when
these rules are broken. For a safety or security concern, use the private
process in [SECURITY.md](SECURITY.md) instead of opening a public issue.
