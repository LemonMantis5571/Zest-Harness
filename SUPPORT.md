# Support

Zest is in beta. Start with the [README](README.md) and the guides in
[`docs/`](docs/), then search existing issues before opening a new one.

- Use the bug report template for reproducible problems.
- Use the feature request template for product ideas.
- Include Zest version, operating system, install method, and a short set of
  steps. Remove API keys, tokens, workspace contents, and personal paths.
- Report security issues privately using [SECURITY.md](SECURITY.md).

Provider quota and cost values may be unavailable or estimated. A local value
is not proof of a provider subscription balance.
